Simplescan 1.2.0: Aufgeräumte Liste und Versand per E-Mail

- Gelöschte Dateien verschwinden von selbst aus „Zuletzt gespeichert“, auf dem Handy wie auf dem Server
- Ist der Server gerade nicht erreichbar, bleiben die Einträge stehen
- Neues Brief-Symbol: lokal gespeicherte PDFs direkt als E-Mail-Anhang verschicken
- Bei Nextcloud kommt ein öffentlicher Link in die E-Mail, den man ohne Anmeldung öffnen kann
- Gleich nach dem Speichern geht der Versand auch über „Per E-Mail“ im Hinweis unten
